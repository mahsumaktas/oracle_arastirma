# Tweets (3–5 pieces)

#

Tweet 1 (Subject: OpenAI Realtime voice):

Does the game now "talk" on the voice agent side? not. Does it reason while listening, does it call tools, does it translate, does it pick up when interrupted? OpenAI's new Realtime trio has raised this threshold to the API level.

Tweet 2 (Topic: RLDX‑1):

The most interesting breakthrough on the robotics side is not the “bigger VLA”, but bringing the physics of the hand into the model: torque, tactile signal, memory. That's why RLDX‑1 is important. Seeing is not enough; It is necessary to model the contact itself.

Tweet 3 (Subject: VS Code 1.119):

The real difference in Agent IDEs will come from observability, not from the model name. Browser sharing + OTel trace + token/tool ​​span = “What did the agent do?” The answer to the question. It is not an agent production system that you cannot debug.

Tweet 4 (Subject: Agent Vault):

Giving secret to agent is anti-pattern in 2026. Correct pattern: agent tells the request, vault/proxy checks authorization, transaction occurs without credential being seen. In the age of prompt injection, security is established not with text but with boundary.
