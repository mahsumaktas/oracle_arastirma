KAT-2 - Research & Papers

#
  • JIT-Agent argues that agent harness quality is as decisive as the model. It makes the memory, planning, action protocol and tool orchestration layer the subject of test-time evolution. Source: https://arxiv.org/abs/2608.25593
  • TOPAS recommends prefix-state scheduling for multi-agent LLM serving. KV cache, long system prompt and workflow-aware scheduling are considered as the main bottleneck of agent service cost. Source: https://arxiv.org/abs/2608.25523

  • Reconstructing the Right Episode examines the problem of finding the right memory section in long conversations. Long context alone is not enough; Episodic retrieval quality should be measured separately. Source: https://arxiv.org/abs/2608.25655
  • FrontierChallenge recommends measuring scientific agents through full workflow completion. Not only the final answer, data analysis, code execution and artifact production are tested together. Source: https://arxiv.org/abs/2608.24979
