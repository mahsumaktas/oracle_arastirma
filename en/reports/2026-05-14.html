# Tweets (3–5 pieces)

#

Tweet 1 (Topic: ToolCUA):

Agent issue is not "connect more tools". The real threshold: when to click on the screen, when to call the API? ToolCUA is trying to train this switch decision. This is the real bottleneck in computer-use agents.

Tweet 2 (Topic: MemPrivacy):

If personal memory products are going to explode, this must be solved first: personalization without sending raw PII/secrets to cloud memory. MemPrivacy points you in the right direction with typed placeholder.

Tweet 3 (Topic: Multi-Stream LLMs):

Chat format is a bottleneck for agents: the model cannot write while reading, cannot take action while thinking. The multi-stream LLM idea is a more fundamental interface change from “longer context”.

Tweet 4 (Subject: DeepMind pointer):

DeepMind's AI pointer idea seems small, but it's big in terms of UX: the era of "look this, move this, change here" instead of writing a prompt. Agent interface exits the chat box.
