# Tweets (3–5 pieces)

#

Tweet 1 (Subject: Claude Opus 4.8):

The real news of Opus 4.8 is not the benchmark: it is able to say "I don't know what" in long jobs and focuses on the agent workflow side. The model race is slowly shifting from “intelligence” to “continuation of work”.

Tweet 2 (Subject: MemTrace):

The problem with LLM memory systems is "does it remember?" not, can you find where you produced the false memory. This is why MemTrace is important: memory debug is now a separate discipline.

Tweet 3 (Subject: LiveBrowseComp):

The dirty secret of browser benchmarks: sometimes the model doesn't search the web, it just confirms what it already knows. LiveBrowseComp is trying to measure this with fresh information. Good slap to the investigative agents.

Tweet 4 (Topic: Edge robotics):

Edge AI robotics side is progressing quietly: Jetson/Orin, on-device VLM, low latency, less cloud dependency. Productization will become more serious as robot "intelligence" flows from the datacenter to the device.
