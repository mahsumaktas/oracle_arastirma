KAT-2 - Arastirma & Paper'lar

#
  • JIT-Agent, agent harness kalitesinin model kadar belirleyici oldugunu savunuyor. Memory, planning, action protocol ve tool orchestration katmanini test-time evrim konusu yapiyor. Kaynak: https://arxiv.org/abs/2608.25593
  • TOPAS, multi-agent LLM serving icin prefix-state scheduling oneriyor. KV cache, uzun system prompt ve workflow-aware scheduling, agent servis maliyetinin ana darboğazi olarak ele aliniyor. Kaynak: https://arxiv.org/abs/2608.25523
  • ReliableRAG, RAG misinformation riskini reliability-guided reasoning chains ile azaltmayi hedefliyor. Bu, kaynak kalitesi dusuk veya celiskili oldugunda chain seviyesinde guvenilirlik kontrolu ekliyor. Kaynak: https://arxiv.org/abs/2608.25487
  • Reconstructing the Right Episode, uzun konusmalarda dogru hafiza bolumunu bulma problemini inceliyor. Long context tek basina yetmiyor; episodic retrieval kalitesi ayri olculmeli. Kaynak: https://arxiv.org/abs/2608.25655
  • FrontierChallenge, scientific agent'lari tam workflow completion uzerinden olcmeyi oneriyor. Sadece final cevap degil, veri analizi, kod calistirma ve artifact uretimi birlikte test ediliyor. Kaynak: https://arxiv.org/abs/2608.24979

KAT-6 - AI Agent'lar

#
  • OpenAI persistent agent sinyali, long-running task governance'ini merkeze aliyor. Agent uyku/uyanma, devam eden görev, interrupt ve kaynak siniri olmadan guvenli olamaz. Kaynak: https://www.wired.com/story/openai-is-developing-a-persistent-ai-agent/
  • Anthropic fiziksel cihaz standardi, agent action space'i real-world risk alanina tasiyor.   • Belief Cascades, multi-agent aglarda ikna ve bilgi yayilimi riskini inceliyor. Coklu agent debate/coordination sistemlerinde yanlis inancin network etkisiyle guclenmesi takip edilmeli. Kaynak: https://arxiv.org/abs/2608.25152
  • Routed Graph Handoff, multi-agent delegasyonda natural language yerine yapilandirilmis graph handoff oneriyor. Handoff metninin token maliyeti ve anlam kaybi, production agent takimlari icin direkt sorun. Kaynak: https://arxiv.org/abs/2608.25277
  • When Stale Constraints Go Unchecked, inherited agent memory icindeki eski kurallarin zararini olcuyor. Compaction ve memory consolidation sonrasi geri cekilmis constraint'lerin kalmasi ciddi operasyonel risk. Kaynak: https://arxiv.org/abs/2608.25553
