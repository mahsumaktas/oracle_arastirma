[Kaynak](https://developer.nvidia.com/blog/accelerating-direct-sparse-solvers-for-computational-engineering-with-nvidia-cudss-1-0/)
- **E13 — Sirius core extension: DuckDB SQL, koşullu GPU execution.** DuckDB 2.0; desteklenen sorgu GPU, diğerleri CPU fallback. Tuned iki-GPU TPC-H türevi deneylerde 3,25–5,50× runtime kazanımı aktarılıyor. **Önem:** Veri analitiğinde mevcut SQL arayüzünü koruyan acceleration. **Güven: HIGH, 23 Kasım vendor/araştırmacı rehberi. Sınır:** Pinned development build'ler; Sirius süresi result fetch/export'u dışlarken CPU ölçümü CSV output'u içeriyor. Query-time compute cost startup/storage/S3/idle'ı dışlıyor; 10TB default iki-GPU koşusu bitmemiş, tuning gerekli. Genel fatura tasarrufu değil. [Kaynak](https://developer.nvidia.com/blog/get-started-with-gpu-accelerated-duckdb-analytics-using-the-sirius-core-extension/)
- **E25 — Speculative decoding'de verifier beklerken drafter'ı paralelleştirmek.** Hidden-state divergence ile layer-level draft state kabulü/correction; yeniden eğitim gerektirmeyen yöntem. **Önem:** Darboğazı draft katmanlarında aramak. **Güven: HIGH abstract/tarihçe, 20 Kasım preprint. Sınır:** Bildirilen **1,65×'e kadar hız draft aşamasına ait**; bütün generation veya hizmet maliyetinin aynı oranda iyileştiği sonucu değil. [Çalışma](https://arxiv.org/abs/2611.27477)

## SAFETY

- **E24 — SplitBench: test çalıştırma ile hüküm verme ayrı yetkiler.** Trusted grader beklenen cevapları tutar; agent kodunun test ortamına hâkim olması pass üretmesine yetmesin diye tasarlanır. 180/202 görev dönüşümü, native grader'larla %98,7 agreement ve adversarial denemelerin %75'ini engelleme aktarılıyor. **Önem:** Verifier da saldırı yüzeyidir. **Güven: HIGH abstract/tarihçe, 20 Kasım preprint.
