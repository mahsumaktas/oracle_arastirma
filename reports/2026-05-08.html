# Tweetler (3–5 adet)

#

Tweet 1 (Konu: OpenAI Realtime voice):

Voice agent tarafında oyun artık “konuşuyor mu?” değil. Dinlerken reasoning yapıyor mu, tool çağırıyor mu, çeviriyor mu, yarıda kesilince toparlıyor mu? OpenAI’nin yeni Realtime üçlüsü bu eşiği API seviyesine çekti.

Tweet 2 (Konu: RLDX‑1):

Robotik tarafında en ilginç kırılma “daha büyük VLA” değil, elin fiziğini modele sokmak: torque, tactile signal, memory. RLDX‑1 bu yüzden önemli. Görmek yetmiyor; temasın kendisini modellemek gerekiyor.

Tweet 3 (Konu: VS Code 1.119):

Agent IDE’lerde asıl fark model isminden değil gözlemlenebilirlikten gelecek. Browser paylaşımı + OTel trace + token/tool span = “agent ne yaptı?” sorusunun cevabı. Debug edemediğin agent üretim sistemi değildir.

Tweet 4 (Konu: Agent Vault):

Agent’a secret vermek 2026’da anti-pattern. Doğru desen: agent isteği söyler, vault/proxy yetkiyi kontrol eder, credential görünmeden işlem olur. Prompt injection çağında güvenlik metinle değil boundary ile kurulur.

# Reply Fırsatları (2–3)

#

@sama altına (Agents SDK 2.0):

Underrated kısmı bence SDK değil, permission + observability + recovery primitive’leri. Agent framework’leri “tool call çalıştı” seviyesinden “operasyon güvenli mi?” seviyesine çıkmak zorunda.

@levie altına (agent engineering roles):

Kesinlikle. Yeni rol “prompt engineer” değil; agent systems engineer: workflow, eval, permission, trace, rollback, cost control. Agent kullanan şirketle agent yöneten şirket aynı şey değil.

@theo altına (60M token Copilot):

Agent cost problemi UX problemi gibi görünür ama aslında control-plane problemi. Budget, stop condition, trace ve per-task quota yoksa model zekası arttıkça fatura da davranış da kontrolden çıkar.
